# Sofle keymap

The [Eyelash Sofle](https://sofleii.dlu.one/) split keyboard's layers, with
every key labelled by what it **does on these machines** rather than what it
sends: NAV's `Super+Shift+K` is drawn as *Mon ↑* because
[`binds.kdl`](https://github.com/rdlu/dotfiles/blob/main/niri/dot-config/niri/binds.kdl)
binds it to `focus-monitor-up`. The firmware and its own key-by-key reference
live in [rdlu/sofleii](https://github.com/rdlu/sofleii); this page joins that
keymap to the configs in this repo.

**Hover or focus a key** for what it sends, what that does, and the line it
comes from. Printable version: [sofle-keymap.pdf](../pdf/sofle-keymap.pdf)
(A4, one page of basics and every layer).

Generated by `tools/gen-docs.py` from a snapshot of the sofleii keymap in
`tools/sofle/` (refresh it with `mise run docs-sofle-sync`) and the live
niri and tmux configs, so a rebind in `binds.kdl` shows up here on the next
build.

{{< sofle-legend >}}

## BASE

Always on. The joystick (centre column) and the left encoder are media keys;
the thumbs hold the other layers.

{{< sofle-layer "BASE" >}}

## NAV

Hold the left thumb's NAV key. The left half drives niri: workspaces on
Tab/Q, monitors on the home row, moving the column on the bottom row, plus
the screenshot column on the inner edge. S and D stay Alt and Ctrl when held.

{{< sofle-layer "NAV" >}}

## CODE

Hold the right thumb's CODE key. Digraphs and snippets typed as one key;
▏ marks where the cursor ends up.

{{< sofle-layer "CODE" >}}

## MEDIA

Hold the right thumb's outer key. Volume and playback through Noctalia and
playerctl; F20 is `XF86AudioMicMute` in xkb, so it toggles the microphone.

{{< sofle-layer "MEDIA" >}}

## SYS|NUM

Hold the left thumb's outer key. Firmware only: Bluetooth profiles,
underglow and the mouse on the left, a numpad on the right.

{{< sofle-layer "SYS|NUM" >}}
